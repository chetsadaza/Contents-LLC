## 🌟 Key Features

- **Editorial Typography Pairing**: Modern, high-conversion typography pairing (Newsreader / Instrument Serif & Plus Jakarta Sans).
- **Pinned Interactive Story Sequence**: Scroll-driven storytelling covering Who We Are, Our Approach, and 6 core AI Capabilities.
- **How It Works**: 3-Phase horizontal slider (Discovery, Strategy & Design, Build & Deploy).
- **Trusted by Brands**: 8-brand marquee infinite loop with performance metrics ($14M+ ad-spend managed, 312% ROAS uplift).
- **Simple Pricing**: Transparent advisory and enterprise plans.
- **Progressive Multi-Step Schedule Wizard**: 4-step booking flow (Plan, Date/Time, Contact Details, Confirmation).
- **Founder Reviews**: 3-column vertical marquee masonry testimonial wall.
- **Interactive FAQ**: Split layout with animated accordion answers.
- **Final CTA**: High-converting closing hook.

## 🚀 Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Vanilla CSS Keyframes & Animations
- **Icons**: Lucide React
- **Language**: TypeScript

---

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/chetsadaza/Contents-LLC.git
cd Contents-LLC/Frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
